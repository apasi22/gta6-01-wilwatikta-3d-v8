# WILWATIKTA 3D — an original open-world crime game

A coastal Javanese city at sunset, built from scratch in raw WebGL: drive and steal
cars, escape the WPD police and their helicopter, fight on foot, run 12 story
missions for Agus Prasetyo, hire crew, tune cars at the garage, and listen to
Gamelan FM while the sun goes down over the Java Sea. No libraries, no assets, no
network — every building, palm, car, and character is generated in code.

## How to play

Serve `game/` with any static HTTP server and open `index.html` in desktop Chrome,
or run `node serve.ts` from the repository root. Keyboard: WASD drive/walk,
E enter/exit car, J shoot, R reload, 1–5 weapons, Z/X/C crew, G garage, M map,
P pause, T radio.

## What is in this version

- Bright saturated pastel sunset, white-hot sun disc, and a full day/dusk/night cycle.
- Realistic palms (segmented ringed trunks, layered drooping fronds, coconuts) and
  street trees with rounded layered canopies; buildings with window grids, balconies,
  cornices, setbacks, awnings, and rooftop clutter.
- Blue WPD response list, crew cards on the left, and a raised weapon bar.
- A front-facing hero on the title screen, and a cover shot where the dialogue
  never covers the hero car.
